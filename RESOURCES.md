# Native Apple Development Resources

## Knowledge

- [The Swift Programming Language](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/)
  Swift's authoritative language guide. Use for: syntax, types, protocols, concurrency, and language semantics.
- [SwiftUI documentation](https://developer.apple.com/documentation/swiftui/)
  Apple's primary framework reference. Use for: app structure, view composition, state, navigation, and platform adaptation.
- [EventKit documentation](https://developer.apple.com/documentation/eventkit/)
  Apple's Calendar and Reminders framework reference. Use for: permissions, querying events, and fetching reminders.
- [Foundation Models documentation](https://developer.apple.com/documentation/foundationmodels/)
  Apple's on-device model API reference. Use for: availability, guided generation, tool use, context limits, and evaluation.
- [Gmail API documentation](https://developers.google.com/workspace/gmail/api/guides)
  Google's first-party API guide. Use for: OAuth, read-only retrieval, message formats, labels, and quotas.
- [CloudKit documentation](https://developer.apple.com/documentation/cloudkit/)
  Apple's private iCloud data API reference. Use for: sharing the Canonical Brief and coordinating a Brief Run.

## Wisdom (Communities)

- [Apple Developer Forums](https://developer.apple.com/forums/)
  Apple's practitioner forum with framework-specific discussions. Use for: platform edge cases after checking official documentation.
- [Swift Forums](https://forums.swift.org/)
  The Swift project's technical community. Use for: language behaviour, evolution, concurrency, and design questions.
