# Threadlight agent instructions

## Teaching

For every implemented issue, use the `teach` skill to add or update beginner lessons under `teach/`. Assume no Apple-development knowledge unless `teach/learning-records/` establishes it. Teach prerequisites before exercises; use exact snippets from the issue's PR; include definitions, expected command results, hints, retrieval practice, and primary sources. Update `teach/index.html` so the issue and lessons are discoverable. The teaching work is complete when the index links every new lesson and the Pages workflow validates it.
