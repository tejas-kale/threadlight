# Native Apple development resources

## Knowledge

- [A Swift Tour](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/guidedtour/)
  Apple's introductory language tour. Use for syntax only when a lesson needs it.
- [Structures and classes](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/classesandstructures/)
  Authoritative explanation of Swift data types. Use for Threadlight's domain structs.
- [Protocols](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/protocols/)
  Authoritative explanation of behavioural contracts. Use for Source Adapter and Brief Store.
- [Retrieving events and reminders](https://developer.apple.com/documentation/eventkit/retrieving-events-and-reminders)
  Apple's EventKit query guide. Use for Calendar permissions and event retrieval.
- [Custom GitHub Pages workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)
  GitHub's supported Pages deployment pattern.

## Wisdom (Communities)

- [Swift Forums](https://forums.swift.org/)
  Swift language community. Use after checking the language documentation.
- [Apple Developer Forums](https://developer.apple.com/forums/)
  Framework practitioner community. Use for EventKit behaviour not resolved by documentation.
