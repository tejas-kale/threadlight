# Mission: Learn native Apple development by building Threadlight

## Why
Build enough practical Swift and Apple-platform knowledge to understand, review, run, and eventually maintain Threadlight rather than approving unfamiliar code blindly.

## Success looks like
- Explain each production slice in everyday language.
- Run it safely and recognise expected behaviour.
- Review a PR by tracing user behaviour through its code and tests.
- Gradually make small Swift changes with guidance.

## Constraints
- Assume no prior Swift, iOS, macOS, Xcode, or Apple-framework knowledge.
- Teach one small idea at a time using examples from the current PR.
- Define every new term and provide exact commands and expected observations.

## Out of scope
- General-purpose Swift mastery before it becomes useful to Threadlight.
- Memorising framework APIs.
