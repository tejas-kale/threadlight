Win: recognise the project’s three parts and prove the code builds without touching Calendar data.

What is Swift?

Swift is the programming language. Swift Package Manager (SwiftPM) is the tool that organises, builds, and tests Swift code. Think Python plus pyproject.toml and pytest, bundled with the compiler.

PR #21 adds this exact package declaration:

.library(name: "ThreadlightCore", targets: ["ThreadlightCore"]),
.executable(name: "threadlight", targets: ["ThreadlightCLI"]),
.testTarget(name: "ThreadlightCoreTests", dependencies: ["ThreadlightCore"])
  • Library: reusable decision-making code.
  • Executable: the command you run.
  • Test target: examples that check behaviour automatically.

Try it

cd /path/to/threadlight
swift build

Expected ending: Build complete!. This compiles code; it does not read your Calendar.
