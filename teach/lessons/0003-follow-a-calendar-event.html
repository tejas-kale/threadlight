Follow a Calendar event

Win: explain how a private Apple Calendar event becomes one grounded Markdown line.

The path

Apple Calendar
      ↓ EventKitCalendarAdapter
SourceObservation
      ↓ ApplicationCore
Markdown with an Evidence Link

EventKit is Apple’s framework for asking permission and reading Calendar data. An adapter translates EventKit’s vocabulary into Threadlight’s vocabulary.

Translation from PR #21

return SourceObservation(
    title: event.title ?? "Untitled",
    startsAt: event.startDate,
    endsAt: event.endDate,
    evidenceLink: link
)

?? means “use the value on the left, otherwise use the fallback”. An untitled event therefore becomes Untitled instead of crashing.

The core keeps observations overlapping today through 10:00 tomorrow, sorts ties predictably, and renders:

- 09:30 [Dentist](<eventkit://event/…>)

The link carries the originating EventKit identifier. That is why the line is evidence-backed rather than an unsupported claim.

Apply it

If EventKit returns an event starting yesterday at 23:00 and ending today at 01:00, should it appear?

Hint

Ask whether any part of the event overlaps the Brief Day window.

Reveal answer

Yes. It is an ongoing commitment after today begins. PR #21 compares both start and end rather than looking only at the start.
