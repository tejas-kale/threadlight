Read your first Swift types

Win: read three Swift shapes in PR #21 without needing to write Swift.

A struct holds related values

public struct SourceObservation {
    public let title: String
    public let startsAt: Date
    public let endsAt: Date
    public let evidenceLink: URL
}

This resembles a frozen Python dataclass. let means the property cannot be reassigned after creation. The text after : is its type.

An enum limits the possible answers

public enum BriefRunOutcome: String {
    case retrieved
    case completed
    case notCompleted = "not completed"
}

Instead of accepting any string, Threadlight permits exactly three outcomes. That makes impossible spellings unrepresentable.

A protocol describes a capability

public protocol SourceAdapter: AnyObject {
    func observations(in window: DateInterval) -> SourceReport
}

A protocol is close to a Python Protocol: it says what an object must do without saying how. Tests provide a controlled adapter; production provides EventKit.
