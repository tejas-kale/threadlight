# Mission: Learn native Apple development by building Threadlight

## Why

Learn Swift, SwiftUI, and Apple-platform development deeply enough to build and
maintain a genuinely useful private daily assistant. The learning stays grounded
in a product used every day rather than disconnected exercises.

## Success looks like

- Build and debug a native macOS daily-brief app without an agent writing its production code.
- Transfer the same concepts to an iPhone companion that can independently generate the brief.
- Make informed choices about permissions, local models, networking, persistence, synchronisation, and testing.
- Run Threadlight safely in shadow mode and decide when it is reliable enough to replace the existing brief.
- Extend the resulting foundation into a private, evidence-linked local RAG assistant.

## Constraints

- Five hours per week, normally as five 60-minute sessions.
- Teach concepts just in time and apply them immediately to a visible vertical slice.
- Tejas types all production code; Codex may teach, clarify, review, and help diagnose.
- Target personal use on macOS 27 and iOS 27 or later, initially outside the Mac App Store.
- Routine interpretation stays on-device; permissions and disclosure remain user-controlled.
- Use British English.

## Out of scope

- Todoist integration.
- Production code authored by a coding agent.
- Mac App Store distribution for the first release.
- ChatGPT or another external LLM as a routine inference dependency.
